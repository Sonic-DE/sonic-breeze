# Sonic Breeze Release Notes

Sonic Breeze keeps the classic Breeze look available in SonicDE as an optional theme, with its window style, colors, icons and desktop layouts.

## 6.8.2 (2026-11-10)

- Breeze desktop layouts now carry SonicDE's own name, so they apply correctly to the SonicDE desktop.

## 6.8.0 (2026-10-20)

- Behind the scenes: version update.

## 6.7.5 (2026-09-12)

- Behind the scenes: version update.

## 6.7.4.7 (2026-08-31)

- The Breeze, Breeze Dark and Breeze Twilight global themes now switch to the matching Breeze styles as intended.

## 6.7.4.6 (2026-08-28)

- The complete classic Breeze icon set is now included, so you can keep the familiar icons everywhere except the rebranded app launcher.

## 6.7.4.5 (2026-08-26)

- Added Breeze icon themes that bring back the original Breeze icons that Silver now draws differently.

## 6.7.4.4 (2026-08-26)

- Fixed the Breeze global themes going missing after installation.

## 6.7.4.3 (2026-08-24)

## 6.7.4.2 (2026-08-17)
